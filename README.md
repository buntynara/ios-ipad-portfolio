### Gazzili Collection – Freemium Content Model

The Gazzili games collection featured approximately six educational subgames or topic-based experiences.

- The first game or topic was available for free.

### Multilingual Localization & Audio Asset Management

The Gazzili educational games supported **10 languages**, providing localized learning experiences for children across different regions.

**Key capabilities**
- English language assets were bundled with the application by default.
- Users could change the application language through the in-app menu.
- The application checked whether the selected language's assets were already available locally.
- If the required assets were not available locally, the application downloaded the language-specific ZIP package.
- Packages contained organized resource folders, including images and audio.
- Downloaded assets were stored locally on the iPad and reused, avoiding repeated downloads.
- Localized voice/audio assets supported narrated learning experiences.

**Engineering focus:** Multilingual localization, language selection, ZIP-based asset delivery, local file storage, conditional downloads, and localized audio integration.

**Puzzle Mechanics:**

- **Map:** Assemble and rotate collected map pieces to complete a map.
- **Tiles:** Swap tiles to reveal a complete picture or code.
- **Make:** Combine different parts to create complete objects based on grouping and dependencies.
- **Organ:** Toggle buttons in rows based on collected codes.
- **Equation:** Place objects into baskets according to their prices and basket limits.
- **Board:** Position objects while satisfying row and column restrictions.
- **Path:** Navigate locked and unlocked paths to reach the destination.
- **Combination:** Unlock doors using key combinations.
- **Scrolling:** Adjust number rolls to satisfy mathematical equations.
- **Box:** Position and rotate objects correctly to open boxes.
- **Weight:** Balance containers using different weights.
- **Circle:** Rotate circular strips to match patterns.
- **Potion:** Arrange pipeline blocks to create paths for mixing liquids.

**Technology:** Objective-C, Cocos2d, In-App Purchase, Big Fish SDK.

**Platform:** Universal iOS (iPhone + iPad).

## **7. Enterprise iPad Applications**

### **PDF Editor – Secure Legal Document Annotation & Review**

An iPad application designed for viewing legal documents, creating PDF annotations and submitting documents to administrators for review.

Administrators could review submitted annotations and respond with approved or commented annotations.

**Key Features:**

- View legal documents and create annotations directly within PDFs.
- Submit annotated documents to administrators for review.
- Receive administrator feedback through annotation replies.
- Continue working on documents without internet connectivity.
- Store annotations and pending changes locally.
- Automatically synchronize pending changes when connectivity is restored.
- Encrypt documents during transmission to protect confidentiality.
- White-label application customization.
- Apple Push Notification Service (APNS) integration.

**Offline-First Synchronization:**

Implemented local persistence for document annotations and pending changes, allowing users to continue working offline. Developed automatic synchronization logic to upload pending changes when connectivity became available, integrating with SOAP-based XML web services.

**Technology:** Objective-C, PSPDFKit, APNS, SOAP/XML Web Services, White Labelling.

**Platform:** iPad.

### **PDF Annotation Toolkit – Medical Document Management**

An enterprise iPad application for viewing medical documents, adding PDF annotations and submitting annotated documents to administrators within the respective medical organization.

**Key Features:**

- View medical documents and add PDF annotations.
- Filter documents using main categories.
- View annotation history.
- Mark documents as favourite or unfavourite.
- Access various reports.
- Global document search.
- Content Management System (CMS) integration.
- Automatic logout after a period of inactivity.
- APNS notification integration.

**Technology:** Swift 3, PDFTron SDK, APNS, CMS Integration.

**Platform:** iPad.
