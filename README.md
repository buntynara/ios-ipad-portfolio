# Educational iPad Applications – Portfolio

A collection of six interactive educational applications for preschool and elementary-age learners. These projects showcase native iPad development, touch-based interactions, educational gameplay, multimedia integration, and child-friendly user experiences.

## Technology Stack

The applications were developed primarily with native iOS technologies:

- **Programming language:** Objective-C
- **UI framework:** UIKit
- **Platform:** Apple iPad
- **Additional capabilities:** In-App Purchases and accelerometer integration, where applicable

The projects demonstrate experience building native iPad interfaces, interactive learning activities, game logic, and device-integrated experiences.

## Portfolio Projects

**Category:** Preschool Educational Game

An interactive puzzle-solving application designed to develop early cognitive skills, spatial awareness, and fine motor coordination.

**Key features**
- Drag-and-drop puzzle interactions optimized for iPad touchscreens.
- Gamified learning activities and self-paced challenges.

## Gazzili Collection – Freemium Content Model

The Gazzili games collection featured approximately six educational subgames or topic-based experiences.

- The first game or topic was available for free.
- Additional games or topics were locked until purchased.
- In-App Purchases enabled users to unlock further educational content.

**Monetization model:** Freemium, with In-App Purchase-based content unlocking.

## Multilingual Localization & Audio Asset Management

The Gazzili educational games supported **10 languages**, providing localized learning experiences for children across different regions.

**Key capabilities**
- English language assets were bundled with the application by default.
- Users could change the application language through the in-app menu.
- The application checked whether the selected language's assets were already available locally.
- If the required assets were not available locally, the application downloaded the language-specific ZIP package.
- Packages contained organized resource folders, including images and audio.
- Downloaded assets were stored locally on the iPad and reused, avoiding repeated downloads.
- Localized voice/audio assets supported narrated learning experiences.

**Engineering focus:** Multilingual localization, language selection, ZIP-based asset delivery, local file storage, conditional downloads, and localized audio integration.
